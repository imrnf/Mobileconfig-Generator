## 💡 Apa ini?

Capek bikin file `.mobileconfig` manual pakai XML? **Mobileconfig-Generator** bikin proses itu jadi cuma isi form & klik tombol. Cocok buat kamu yang mau setup DNS privasi atau VPN di iPhone/iPad tanpa pusing.

---

## ✨ Fitur Unggulan

🌐 **DNS Configuration**
> Setup DNS-over-HTTPS (DoH) atau DNS-over-TLS (DoT) untuk privasi maksimal di iOS 14+. Termasuk fallback IPv4/IPv6.

🔒 **VPN Configuration**
> Generate profil VPN L2TP/IPSec atau IKEv2 lengkap dengan kredensial & shared secret — siap install.

⚡ **Instant & Lightweight**
> Berbasis web, tanpa instalasi, tanpa backend. Generate langsung di browser.

🎯 **User-Friendly Form**
> Tampilan bersih, field jelas, placeholder membantu — bahkan untuk pemula sekalipun.
